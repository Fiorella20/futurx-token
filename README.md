*Token Name*: FuturX  
*Symbol*: FTRX  
*Blockchain*: Solana  
*Token Type*: SPL  
*Mint Address*: 6VdVk3ngmTDBrZDgHCWE3U1VmKFmFTh5mnN43LJQeE9U  
## Description
FuturX is a token created on Solana to support the development of the *Quantum Santa Claus Village*, a permanent wonderland for children with disabilities and their families.  
The project merges crypto innovation with global social impact.
